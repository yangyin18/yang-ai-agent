# 恋爱心理学基础理论

## 1. 爱情三角理论（Robert Sternberg）
爱情由三个核心要素组成：
- **亲密（Intimacy）**：情感层面的亲近、理解与分享
- **激情（Passion）**：生理吸引与浪漫冲动
- **承诺（Commitment）**：决定去爱并维持关系的决心

七种爱情类型：
| 类型 | 成分 | 特点 |
|------|------|------|
| 喜欢式爱情 | 仅亲密 | 友谊式，无激情和承诺 |
| 迷恋式爱情 | 仅激情 | 一见钟情，短暂热烈 |
| 空洞式爱情 | 仅承诺 | 包办婚姻，无感情基础 |
| 浪漫式爱情 | 亲密+激情 | 热恋期，缺乏长期承诺 |
| 伴侣式爱情 | 亲密+承诺 | 老夫老妻，激情消退 |
| 愚蠢式爱情 | 激情+承诺 | 闪婚，缺乏深入了解 |
| 完美式爱情 | 三者齐全 | 理想状态，需要长期经营 |

## 2. 依恋理论
四种依恋类型影响成年后的亲密关系模式：

| 类型 | 特征 | 恋爱表现 |
|------|------|---------|
| 安全型 | 信任他人，自尊高 | 能建立稳定关系，沟通顺畅 |
| 焦虑型 | 缺乏安全感，害怕被抛弃 | 过度依赖，频繁求证对方爱意 |
| 回避型 | 情感疏离，不信任亲密 | 害怕亲密，经常逃避承诺 |
| 恐惧型 | 既渴望又害怕亲密 | 矛盾纠结，忽冷忽热 |

## 3. 男女思维差异
| 维度 | 男性思维 | 女性思维 |
|------|---------|---------|
| 沟通 | 解决问题导向 | 共情理解导向 |
| 压力处理 | 独处冷静（洞穴期） | 倾诉获得支持 |
| 亲密需求 | 行为层面的认可 | 情感层面的连接 |
| 冲突应对 | 直接对抗或逃避 | 情绪表达与迂回 |

## 4. 恋爱发展阶段
1. **相识期**：第一印象与吸引力建立
2. **暧昧期**：试探与关系界定
3. **热恋期**：理想化伴侣，高度亲密
4. **磨合期**：差异显现，冲突频发
5. **稳定期**：接纳差异，建立信任
6. **承诺期**：共同规划未来
